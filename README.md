# OTOY Studio

Welcome to the OTOY Studio public repository! This is the official space for community feedback, bug reports, feature requests, and discussions about [OTOY Studio](https://otoy.studio/).

> **Formerly AI Canvas.** OTOY Studio is the new name for AI Canvas. Existing issues, discussions and links in this repository still work.

> **Note**: This repository is for issues and discussions only. The source code for OTOY Studio is maintained separately.

## What is OTOY Studio

[OTOY Studio](https://otoy.studio/) is a browser-based, node-based workspace for AI image, video, 3D, Gaussian splat and audio generation, from the team behind OctaneRender. You connect models on one canvas, compare them on the same prompt, and pay with one credit balance. There is a free plan with 100 credits a month.

- [All models and prices](https://otoy.studio/models): every model on the canvas, with its credit cost
- [How-to guides](https://otoy.studio/guides): step-by-step workflows for common tasks
- [Connect a coding agent (MCP)](https://otoy.studio/mcp): use OTOY Studio from Claude Code, Codex, Cursor and other MCP clients
- [Pricing](https://otoy.studio/pricing): plans and credits
