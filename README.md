# AI Canvas

Welcome to the AI Canvas public repository! This is the official space for community feedback, bug reports, feature requests, and discussions about AI Canvas.

> **Note**: This repository is for issues and discussions only. The source code for AI Canvas is maintained separately.

## How to Contribute

### Report a Bug

Found an issue? [Create a bug report](../../issues/new/choose) and our team will investigate.

### Request a Feature

Have an idea to improve AI Canvas? [Submit a feature request](../../issues/new/choose) and let us know!

### Join the Discussion

For general questions, sharing ideas, or community discussions, visit the [Discussions](../../discussions) tab.

## Community Guidelines

- Be respectful and constructive
- Search existing issues before creating a new one
- Provide clear and detailed information
- Stay on topic
